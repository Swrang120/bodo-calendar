# Bodo Calendar (बर' दान)

Traditional Bodo Solar Calendar web application built with HTML, Tailwind CSS, JavaScript, and GitHub Pages.

## Features
- Complete 12 Bodo Solar Months & Weekday translations.
- Live Today Event Detector.
- Admin Live Notifications (`notifications.json`).
- Personal Notes system (Exam, Birthday, Pension, etc.) saved in browser `localStorage`.
- VIP Ad-Free subscription integration.
- PWA ready (`manifest.json`).

## Setup & Deployment
1. Clone repository to your local machine or edit directly on GitHub.
2. Commit files to main branch.
3. Go to Repo **Settings -> Pages**.
4. Select `main` branch and `/root` folder, then save.
5. Your web app will be live on GitHub Pages!
